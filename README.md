# Memory Lane -- Сохраним память вместе

Интерактивный веб-проект, посвященный памяти, истории и людям Великой Отечественной войны (1941-1945 гг.) с особым акцентом на историю и героев Беларуси. Проект представляет собой цифровую дорогу памяти через 1418 дней потерь, стойкости и подвига.

Ссылка на проект: https://viktyfirir.github.io/memory-lane/

---

## О проекте

Сайт задуман как интерактивное путешествие во времени, помогающее прочувствовать масштаб исторических событий через судьбы конкретных людей. Проект структурирован так, чтобы переходить от личных историй солдат к глобальной хронике и интерактивной визуализации военных действий.

### Основные разделы и возможности:
*   Люди и Герои: Интерактивные карточки с реальными историями советских солдат, партизан и подпольщиков (таких как В. З. Хоружая, И. А. Счастный, М. Т. Курбатов).
*   Дорога Памяти (Хроника 1941-1945): Поэтапный разбор войны по главам -- от внезапного удара в 1941 году до победного мая 1945 года.
*   Поворотные сражения: Исторический контекст ключевых битв (Сталинградская, Курская, а также оборона Гродно в 1939 году).
*   Места боевой славы: Интерактивная карта военных объектов и линий фронта с возможностью масштабирования, переключения слоев (линии фронта, направления наступлений) и поиском по локациям.

---

## Стек технологий

Проект реализован на базе современных веб-технологий без использования тяжелых фреймворков, что обеспечивает быструю загрузку и плавную анимацию:

*   HTML5 -- семантическая разметка и структура страниц.
*   CSS3 -- адаптивная верстка (Flexbox, Grid), кастомные шрифты и плавные переходы.
*   Vanilla JavaScript -- логика интерактивных элементов, управление слайдерами, фильтрами, поиском и интерактивной картой.

## Локальный запуск

Вы можете запустить этот проект на своем компьютере:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```

2. Перейдите в папку проекта:
   ```bash
   cd memory-lane
   ```

3. Запустите проект:
   * Так как проект написан на чистом JavaScript, достаточно просто открыть файл index.html в любом браузере.
   * Также можно использовать расширение Live Server в VS Code для локального хостинга.
